Screen capture

Snipper

Capture your screen, mark it up, send it.

  • Download

First release. Capture, annotation and the editor are driven on a real X server on every change — the application is started, a region is dragged out, and the result is checked against the pixels that were on screen.

Two things it does not do yet. Under Wayland the capture is handed to the desktop’s own screenshot portal, which is tested here against a stand-in that follows the specification rather than against a real GNOME or KDE session. And a region is selected on one monitor: the overlay covers the screen the window is on, so a selection cannot be dragged onto a second one. A full-screen capture still takes every monitor.

What it does

  • Capture. A region or the full screen, from a hotkey.
  • Annotate. Pen, highlighter, arrows, shapes and text.
  • Redact. Removes what is underneath, for real.
  • Number the steps. Markers that count themselves.
  • Finish. Copy to the clipboard, or save as PNG or JPEG.
  • Private. Nothing is uploaded. No share link, no account.
